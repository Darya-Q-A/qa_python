Тестируемое приложение: BooksCollector.
 Оно позволяет установить жанр книг и добавить их в избранное.

 ## Основные функции класса `BooksCollector`

- Добавление новой книги (`add_new_book`)
- Установка жанра для книги (`set_book_genre`)
- Получение жанра книги (`get_book_genre`)
- Получение списка книг по жанру (`get_books_with_specific_genre`)
- Получение всех книг и их жанров (`get_books_genre`)
- Получение списка книг, предназначенных для детей (`get_books_for_children`)
- Добавление книги в список избранных (`add_book_in_favorites`)
- Удаление книги из списка избранных (`delete_book_from_favorites`)
- Получение списка избранных книг (`get_list_of_favorites_books`)

## Описание тестов

### 1. `test_add_new_book_length_less_than_40`
Проверяет, что книга с названием длиной менее/равно 40 символов успешно добавляется. После вызова метода название книги присутствует в словаре `books_genre`.

### 2. `test_add_new_book_length_more_than_40`
Проверяет, что книга с названием длиной более 40 символов/пустым названием не добавляется в коллекцию. Название книги отсутствует в словаре `books_genre` после попытки добавить.

### 3. `test_set_book_genre_book_in_dictionary`
Убеждается, что для существующей книги можно установить жанр. После вызова `set_book_genre` название книги отображается с назначенным жанром в `books_genre`.

### 4. `test_set_book_genre_book_not_in_dictionary`
Проверяет поведение при попытке установить жанр для несуществующей книги. Жанр для такой книги не создается или не изменяется.

### 5. `test_get_book_genre_get_true`
Проверяет, что метод `get_book_genre` возвращает правильный жанр для существующей книги. Значение соответствует установленному жанру.

### 6. `test_get_books_with_specific_genre_list_of_books_show`
Убеждается, что метод `get_books_with_specific_genre` возвращает список книг для заданного жанра. Все книги в списке принадлежат этому жанру.

### 7. `test_get_books_genre_show_dictionary`
Проверяет, что метод `get_books_genre` возвращает полный словарь всех книг и их жанров. Содержимое соответствует добавленным книгам.

### 8. `test_get_books_for_children_is_not_genre_age_ratingp`
Гарантирует, что `get_books_for_children` возвращает только книги (названия), предназначенные для детей или соответствующие возрастным критериям.

### 9. `test_add_book_in_favorites_book_added`
Проверяет, что книга успешно добавляется в список избранных при вызове `add_book_in_favorites`. После добавления книга присутствует в списке.

### 10. `delete_book_from_favorites_book_deleted`
Проверяет, что после вызова `delete_book_from_favorites` книга удаляется из списка избранных. В списке ее уже нет.

### 11. `test_get_list_of_favorites_books_true`
Убеждается, что `get_list_of_favorites_books` возвращает актуальный список добавленных в избранное книг.
